# FinSet Dashboard

FinSet is a personal finance dashboard UI built with React, Vite, and Tailwind CSS. The goal is to recreate a polished finance dashboard experience with sections for balances, income, expenses, savings, budgets, transactions, and financial goals.

## Tech Stack

- React
- Vite
- Tailwind CSS
- ESLint

## Getting Started

```bash
cd finest-dashboard
npm install
npm run dev
```

## Available Scripts

Run these from the `finest-dashboard` folder:

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Environment Variables

Create a local `.env` file from the root example when needed:

```bash
copy ..\.env.example .env
```

Real `.env` files are ignored by Git, so secrets and local settings stay off GitHub.

## Current Direction

The dashboard should move toward a feature-based structure, keeping reusable UI components separate from dashboard-specific sections and finance data.
